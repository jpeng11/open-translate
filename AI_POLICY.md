# AI Usage Policy

Open Translate is developed with AI coding agents in the loop — this repo was
largely built that way, and agent contributions are welcome. That works only
if a few rules hold:

- **Disclose AI usage in contributions.** Say which tool you used (Claude,
  Cursor, Codex, Gemini CLI, etc.) and roughly how much of the work it did.
  This isn't a mark against your PR; it just helps reviewers know where to
  look harder.

- **A human must understand every change they submit.** If you can't explain
  what your diff does and why — without asking the model — don't submit it.
  Agents make confident mistakes, and the project invariants in
  [AGENTS.md](AGENTS.md) exist because breaking them fails silently.

- **AI output must be edited, not pasted.** Issues, PR descriptions, and code
  comments generated by a model tend to be verbose and padded. Trim them to
  what a human reviewer actually needs.

- **Green checks are the floor, not the bar.** `pnpm compile`, `pnpm test`,
  and `pnpm build` must pass, but passing them doesn't mean the change is
  right — especially anywhere near the batch translation protocol, Grok OAuth
  headers, or DOM restore logic.

- **Never let an agent commit secrets.** No API keys, tokens, or `.env` files
  in diffs, logs, test fixtures, or issue reports. This extension's whole
  privacy story is that credentials never leave the user's machine.

Low-effort AI slop — contributions the submitter clearly never read — will be
closed without detailed review.
