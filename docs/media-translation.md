# Images, captions and live speech

The image reader includes English, Simplified Chinese and Japanese models in the installation. The OCR language picker also offers 124 official Tesseract language models; a selected additional model downloads once and is cached in the extension profile for offline reuse. The download is data, never executable JavaScript or WebAssembly. The manifest pins the official `tessdata_fast` repository to commit `87416418657359cb625c412a48b6e1d6d41c29bd`, including each file's size and Git object digest, and verifies the bytes before initialization. The model data is Apache-2.0.

OCR jobs run serially in a bundled local Tesseract worker. Tesseract.js 7.0.0 contains an object-language initialization typo: its loader uses `.code` and `.data` but its initializer joins `.data` as the language name. The build applies a narrowly checked correction to use `.code`; it fails if the expected upstream code changes. No remote worker scripts are loaded. Bundled model loading and additional French model initialization/offline reuse have browser acceptance coverage.

Image translation masks glyph pixels inside recognized word boxes and reconstructs their backgrounds with local harmonic interpolation. Original pixels outside those boxes remain intact. Text placement fits the recognized region, respects right-to-left direction, and wraps grapheme clusters without breaking combining marks. This removes the previous unconditional white rectangles. It is not a trained image-restoration model: complex textures, lettering over detailed illustrations, recognition errors and undersized regions still require review. It cannot reproduce arbitrary artistic lettering or guarantee the original service's image quality.

Website subtitles are read from native HTML video/audio text tracks, common player DOM caption containers, and open shadow roots. New tracks and roots are discovered during playback. Disabled native tracks can be enabled in hidden mode while translating and their previous mode is restored when translation stops. Supplied SRT, VTT and ASS/SSA sidecars can be attached as native cues with their original times. The bilingual overlay follows fullscreen changes and supports right-to-left text. Closed shadow roots, private player APIs and encrypted caption streams cannot be inspected through ordinary DOM access.

Screen subtitle capture is an explicit fallback: the user selects a browser tab or screen, local OCR reads its lower 30% every two seconds, and only changed recognized text goes to the configured translation provider. It runs one OCR/translation job at a time. Protected video may appear black because the browser restricts capture; the extension does not bypass that restriction. Capture stops and releases tracks when the user stops sharing.

Live microphone/tab audio now uses an AudioWorklet and independently encoded 16-kHz mono PCM WAV segments. The default segment is three seconds, configurable from two to five seconds. Voice activity detection finishes a segment after approximately 500 ms of silence and avoids uploading idle silence. Each timestamp derives from captured sample counts. The queue is limited to four segments and capture stops rather than silently dropping audio when processing falls behind. A PCM ScriptProcessor fallback is available where AudioWorklet is unavailable. Stop finishes queued transcription; cancellation discards queued results.

The speech endpoint is OpenAI-compatible `/v1/audio/transcriptions`. A separately configured hosted or local endpoint takes precedence. With the local bridge selected and speech URL empty, the extension derives the bridge's `/v1/audio/transcriptions` route and preserves its authentication token. The bridge can run an optional local whisper.cpp model. AGY remains the translation engine; speech recognition runs separately. Short chunks reduce capture latency, but endpoint latency and short-utterance recognition quality still affect the result. This is chunked transcription, not a streaming token/audio protocol.

Primary references: [Tesseract.js API](https://github.com/naptha/tesseract.js/blob/master/docs/api.md), [official fast OCR models](https://github.com/tesseract-ocr/tessdata_fast/tree/87416418657359cb625c412a48b6e1d6d41c29bd), [AudioWorklet](https://developer.mozilla.org/en-US/docs/Web/API/AudioWorklet), [TextTrack cues](https://developer.mozilla.org/en-US/docs/Web/API/TextTrack/cues).
